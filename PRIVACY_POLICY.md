# Privacy Policy — superseded

This file held a NexLink-only privacy policy. **It is no longer the current
document and should not be relied on.**

One policy now covers every NexLink product — NexLink, NexLink Social, NexLink
for Wear OS and NexLink Bridge — in English and German, written to satisfy both
Australian and Swiss law:

- **Published:** <https://thvjq.com.au/nexlink/legal/privacy/> (Deutsch: `/de/`)
- **Source:** `docs/legal/` in [THVjQ/NexLink-Social](https://github.com/THVjQ/NexLink-Social)

The file is kept as a pointer rather than deleted because it is linked from
older release notes and from the store listing history. It was replaced on
2026-09-21, when leaving a second, narrower policy in the repository became a
way for the two to contradict each other — which for a privacy policy is worse
than having none.
