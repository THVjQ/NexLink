# Vendored: rustls-platform-verifier (Android)

`CertificateVerifier.kt` is **not our code.** It is the Android half of the
`rustls-platform-verifier` crate, which the Matrix Rust SDK calls **by JNI class
name** to validate TLS against Android's own trust store.

## Why it is copied in rather than depended on

It is not published to Maven Central in any usable form — upstream ships it
inside a Rust crate that you are expected to locate and use as a local Maven
repository. Element X Android vendors the same single file for the same reason
and documents it in `libraries/rustls-tls/README.md`.

## Why it is mandatory

Without it on the classpath, **every network call the SDK makes fails**, in two
stages that look unrelated:

1. `InternalException: Expect rustls-platform-verifier to be initialized`
   — before `initPlatform(...)` is called;
2. `failed to call native verifier: Error` — after `initPlatform`, when the
   Rust side cannot find this class.

Neither error mentions a missing dependency, and neither is in the SDK's README.
See docs/social/11-sdk-selection.md §11.7.4.
